# 설계한눈 카카오 AdFit 운영

공개 랜딩 페이지의 `업무 흐름`과 `기능 시연` 사이에 인라인 배너 한 곳을 운영한다. PC는 728×90, 모바일은 320×100 전용 광고단위를 사용한다. 로그인·회원가입·초대·조직 승인·실제 업무·문서 작성·사이트 관리자 화면에는 광고를 노출하지 않는다.

고정·전면·팝업·보상형 광고와 애플리케이션 자체 새로고침은 사용하지 않는다. 업무 조작을 가리거나 민원·조직 정보와 광고가 한 화면에 혼재하는 일을 피한다.

## 설정

AdFit Web 매체 `설계한눈`(`NDJ`, `seolgyehannun.designboard.net`)에 아래 전용 단위를 발급해 `src/adfitConfig.ts`에 연결했다. 다른 서비스의 단위를 재사용하지 않는다.

| 화면 | 규격 | 광고단위 |
| --- | --- | --- |
| 모바일 | 320×100 | `DAN-F1SvIBI8e9z004AS` |
| PC | 728×90 | `DAN-XGZYKOeTebfHnIAb` |

광고 영역이 보이기 200px 전에 도달했을 때 한 번만 요청한다. 컨테이너 폭이 320px보다 좁거나 `AdMobNative/1` User-Agent인 WebView에서는 요청하지 않는다. SDK 오류, NOAD 콜백 또는 30초 안에 광고 프레임이 생성되지 않으면 광고와 확보 공간을 함께 제거한다.

## 운영 확인

1. `pnpm test -- src/test/adfit-config.test.ts`와 `pnpm build`를 통과한다.
2. PC·모바일에서 각 전용 단위를 한 번만 요청하는지 확인한다.
3. 광고 차단, 느린 네트워크, NOAD에서 빈 영역이 사라지는지 확인한다.
4. 공개 서비스의 개인정보처리방침에 카카오 AdFit의 쿠키·온라인 식별자·IP 주소·브라우저 및 기기 정보 처리를 고지한다.
5. AdFit에서 공개 URL의 최초 광고 요청을 확인한 뒤 매체 심사 상태를 확인한다.

Firebase Hosting의 CSP는 AdFit 스크립트와 안전 프레임에 필요한 `https://t1.kakaocdn.net`만 `script-src`와 `frame-src`에 허용한다.
